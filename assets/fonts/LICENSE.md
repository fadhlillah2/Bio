# Font licences

The three webfonts in this directory are self-hosted rather than loaded from
Google Fonts, so the site makes no third-party request on page load. All three
are licensed under the **SIL Open Font License 1.1**, which permits bundling and
redistribution as part of a website.

| File | Family | Copyright | Source |
|-----------------------------|-------------------|--------------------------------------|--------------------------------------------------------|
| `instrument-sans-var.woff2` | Instrument Sans | Copyright 2022 The Instrument Sans Project Authors | https://github.com/Instrument/instrument-sans |
| `instrument-serif.woff2` | Instrument Serif | Copyright 2023 The Instrument Serif Project Authors | https://github.com/Instrument/instrument-serif |
| `jetbrains-mono-var.woff2` | JetBrains Mono | Copyright 2020 The JetBrains Mono Project Authors | https://github.com/JetBrains/JetBrainsMono |

Each file is the `latin` subset as served by Google Fonts; the sans and mono
files are variable fonts covering weights 400–700 in a single file.
