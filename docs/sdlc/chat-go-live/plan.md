## 0. Ringkas

Widget chat sudah lengkap (`src/lib/components/ChatBot.svelte`, `src/lib/chat.js`, `worker/chat.ts`, guard bersama `scripts/chat-core.ts`) tetapi `PROD_ENDPOINT` di `src/lib/chat.js` masih kosong sehingga tidak pernah terbit. Plan ini:

1. memperluas grounding backend ke fakta yang sudah terbit di situs (Fineksi, availability 40–60 jam/minggu, tag Kubernetes) lewat satu fungsi ekstraktor yang dipakai proxy dan generator, dijaga gerbang `--check` yang sudah ada;
2. memindahkan provider produksi ke GLM `glm-5.3-flash` (`https://open.bigmodel.cn/api/coding/paas/v4`) dan mengirim `thinking: {type:"disabled"}` khusus endpoint bigmodel;
3. menambah kuota harian per pemanggil (temuan KV-03) di samping kuota global dan rate limit edge;
4. mengganti kalimat pembuka panel dengan disclosure AI + pihak ketiga yang deskriptif;
5. menambah workflow GitHub Actions yang men-deploy worker hanya setelah dua gerbang hijau;
6. memperbarui dokumen hidup (README, CLAUDE.md, cv/README.md) termasuk koreksi klaim "spend cap per kunci";
7. satu tugas terakhir mengisi `PROD_ENDPOINT` — baru bisa dikerjakan setelah user men-deploy worker (gate BERHENTI).

Semua kontrol lama (Origin allowlist tanpa union dev origins, rate limit edge, HMAC giliran assistant, `clampReply`, batas body 413, gerbang konfigurasi fail-closed di atas `/health`, fail-safe widget) tidak boleh berubah perilakunya; test yang sudah ada di selftest tetap lulus apa adanya.

## 1. Keputusan plan (menutup titik yang spec serahkan ke plan)

- **D1 — Ekstraktor hidup di `scripts/chat-proxy.ts`** sebagai `export function siteFacts(repo: string): string`. Alasannya: `scripts/chat-worker-build.ts` sudah mengimpor `currentResume`/`agentFile` dari modul yang sama, jadi kedua backend + generator memakai satu fungsi tanpa berkas baru.
- **D2 — Kuota per pemanggil habis ⇒ HTTP 429** `{"error":"You have reached today's question limit. Please use the contact section."}`. Membedakan dari 503 kuota global; widget menampilkan pesannya apa adanya.
- **D3 — Copy disclosure panel (persis):** `Answers are generated by an AI model from the CV on this site and facts already published on it, and your questions are sent to a third-party model provider. It can be wrong — check anything important against the CV.` Nama model tetap tampil di header. Tanpa tautan tambahan (OQ-7 default).
- **D4 — `CHAT_TOKEN` tidak ikut daftar `secrets:` wrangler-action.** Nilai kosong akan memasang secret kosong; deployment publik default memang tanpa token. Instansi privat yang mau token: `wrangler secret put CHAT_TOKEN` manual (didokumentasikan di README).
- **D5 — Pemicu job worker (paths):** `worker/**`, `scripts/chat-core.ts`, `scripts/chat-proxy.ts`, `scripts/chat-worker-build.ts`, `cv/resume-v*.txt`, `.opencode/agent/bio-guide.md`, 7 komponen sumber fakta situs (About, Hero, Resume, Portfolio, HomeHead, Services, Skills), dan berkas workflow itu sendiri (`.github/workflows/deploy-worker.yml`, supaya edit gerbang/versi action ikut dijalankan). Plus `workflow_dispatch`.
- **D6 — `max_tokens` tetap 700.** Probe: puncak 389 token completion pada mode default, ≤110 dengan thinking disabled; margin cukup untuk 2–5 kalimat. Naikkan hanya kalau AC-03 (uji nyata) menunjukkan `content` kosong/terpotong.
- **D7 — `thinking` digerbang dari hostname endpoint** (`new URL(endpoint).hostname.endsWith('bigmodel.cn')`), bukan variabel baru; endpoint non-GLM tidak boleh menerimanya.

## 2. Kontrak data: blok SITE FACTS (persis)

Keluaran `siteFacts(repo)` harus persis blok ini (deterministik, tanpa tanggal; label tiap baris punya anchor yang diperiksa, kutipan verbatim dari komponen):

```
SITE FACTS — statements already published on fadhlillah2.github.io/Bio, quoted from the page. Some of these are published only on the site, not in the CV document: answer from this block and do not claim where the CV shows them.

- About section, "Current" fact: "Software Engineer — Fineksi"
- Experience timeline, Fineksi entry: "Software Engineer", dates "Present"
- Hero proof list "Production systems built at": "Fineksi"
- Project Showcase, flagship card: "Fineksi — Financial Document Processing"
- JSON-LD "worksFor": "Fineksi"
- Services section: "Freelance Availability: 40–60 hours/week · Jakarta (UTC+7)."
- Skills section, "DevOps / Cloud" group: "Kubernetes"
```

Tabel ekstraksi (berkas sumber → anchor wajib → kutipan; anchor tidak ketemu / lebih dari satu match ⇒ `throw` dengan pesan menyebut berkas dan anchor):

### T5 — Kuota harian per pemanggil (KV-03)

- **Berkas:** `worker/chat.ts`, `worker/wrangler.toml`, `scripts/chat-worker-dev.ts` (runner lokal), `scripts/chat-proxy-selftest.ts`.
- **Prasyarat:** T4.
- **Isi:**
  - `Env` + pembacaan `numberEnv('CHAT_DAILY_PER_CALLER', env.CHAT_DAILY_PER_CALLER, 20)` ikut di gerbang konfigurasi; `worker/wrangler.toml` menambah `CHAT_DAILY_PER_CALLER = "20"` dengan komentar.
  - Urutan wajib: setelah body di-parse, **cek per pemanggil lebih dulu** (key `caller:<utcDay>:<caller>`, TTL 172800, pakai helper `countDay` yang ada), baru kuota global di-charge. Pemanggil yang sudah lewat batas ⇒ 429 (D2) dan **tidak** membakar jatah global; pemanggil lain tetap dilayani. Kuota global dan rate limit edge tidak berubah.
  - `scripts/chat-worker-dev.ts` (`bun run chat:worker`): teruskan `CHAT_DAILY_PER_CALLER: process.env.CHAT_DAILY_PER_CALLER` di literal `Env` dan perbarui komentar header — semua request lokal memakai pemanggil yang sama (`cf-connecting-ip: 127.0.0.1`), jadi tanpa forwarding kuota baru tidak bisa di-override (pertanyaan ke-21 dalam satu proses kena 429 default 20); tidak ada gerbang CI yang menjalankan berkas ini.
- **Test dulu, lalu cara membuktikan selesai:** env test memuat `RATE_LIMITER` stub yang lulus (agar jalur fallback KV `rate:` tidak ikut menulis `put`) + fetch stub T4; mock KV **sadar-kunci**: `get` mengembalikan `"20"` HANYA untuk key yang berakhir `:9.9.9.9`, `null` untuk key lain (mock literal "20 untuk semua key `caller:`" membuat B ikut tertolak dan assert mustahil hijau), `put` mencatat key ke array:
  - `"a caller over its daily allowance is refused while another caller is served"` — A (`cf-connecting-ip: 9.9.9.9`) ⇒ 429 + pesan memuat `contact`; lalu B (`8.8.8.8`) ⇒ 200.
  - `"a refused caller does not spend the global daily budget"` — dievaluasi tepat setelah request A: array `put` masih kosong (tidak ada key `day:` maupun `caller:`); setelah B diterima, key `day:` tertulis tepat sekali.
